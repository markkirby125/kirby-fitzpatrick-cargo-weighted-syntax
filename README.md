Position heavy technical concepts and error terms in the emphatic end-focus position to maximize cognitive resonance and clarity.

## Overview

The **Cargo-Weighted Syntax Engine** places the heaviest cognitive payload (new technical concepts, critical error types, architecture decisions) in the emphatic terminal position of sentences, preventing anti-climactic fade-outs in technical writing.

## Core Patterns

- **End-Focus Invariant**: Flow from known context to heavy technical payload.
- **Anti-Sandwich Rule**: Avoid trapping key insights between subjects and trailing prepositional fluff.
- **Climax & Cadence**: Conclude architectural claims on the definitive decision or metric.
